6  SCS Curve Number method

The SCS Curve Number (CN) method estimates the depth of direct runoff from a rainfall event. It was developed by the Soil Conservation Service, an agency within the United States Department of Agriculture (USDA). SCS was renamed the Natural Resources Conservation Service (NRCS) in 1994.

CN is a dimensionless index combining land cover and land use, hydrologic soil group, and antecedent wetness. A larger CN produces more direct runoff for the same rainfall depth. Initial estimates can be obtained from the SCS/TR-55 curve number tables. The tabulated values refer to specified cover and soil conditions and an average antecedent runoff condition; an application should check whether those conditions represent the catchment and event.

6.1 Retention, initial abstraction and runoff

The potential maximum retention \(S\) is calculated from CN as

\[ S=\frac{25400}{\mathrm{CN}}-254, \qquad 0<\mathrm{CN}\leq100, \]

where \(S\) is in millimetres. The alternative expression \(1000/\mathrm{CN}-10\) gives \(S\) in inches. Do not combine that expression with precipitation in millimetres.

For \(\mathrm{CN}=100\), \(S=0\) and all rainfall becomes direct runoff in this model. At \(\mathrm{CN}=0\), the expression for \(S\) is undefined; zero is excluded from the calculation. As CN approaches zero from above, retention increases and the predicted runoff from a fixed rainfall depth tends to zero.

The initial abstraction \(I_a\) represents losses before direct runoff begins, including interception, depression storage and infiltration. This chapter uses the conventional assumption associated with the TR-55 tables:

\[ I_a=0.2S. \]

The cumulative direct runoff depth \(Q\), also called precipitation excess \(P_e\), is then

\[ Q(P)= \begin{cases} 0, & P\leq I_a,\\[4pt] \dfrac{(P-I_a)^2}{P-I_a+S}, & P>I_a. \end{cases} \]

Here \(P\) is the cumulative rainfall depth since the start of the event. The quantities \(P\), \(I_a\), \(S\) and \(Q\) are all expressed in mm. The parameter \(S\) describes potential retention after runoff begins, rather than an additional fixed loss to subtract from every rainfall observation. These equations follow the HEC-HMS description of the SCS CN loss model.

In this chapter, \(Q\) denotes a depth over the catchment area. It is not a volumetric discharge in \(\mathrm{m^3\,s^{-1}}\). For an area \(A\) in m\(^2\), the corresponding runoff volume is \(V=(Q/1000)A\) in m\(^3\); the CN equations alone do not describe the timing of discharge at the catchment outlet.

6.1.1 Calculation in R

The function below accepts one CN and a vector of rainfall depths. Missing rainfall values remain NA. CN must be a finite number in the interval \((0,100]\), and non-missing rainfall values must be finite and non-negative.

Code 
scs_cn_method <- function(P, CN) {
  stopifnot(is.numeric(CN), length(CN) == 1L,
            is.finite(CN), CN > 0, CN <= 100,
            is.numeric(P),
            all(is.na(P) | (is.finite(P) & P >= 0)))

  S <- 25400 / CN - 254
  Ia <- 0.2 * S

  ifelse(P <= Ia, 0, (P - Ia)^2 / (P - Ia + S))
}
1
Calculate potential maximum retention in mm.
2
Calculate initial abstraction using the same coefficient as in the equations above.
3
Return zero until rainfall exceeds initial abstraction. This condition also gives zero for \(P=0\) and \(\mathrm{CN}=100\).

For example, with \(P=50\) mm and \(\mathrm{CN}=75\):

Code 
CN <- 75
S <- 25400 / CN - 254
Ia <- 0.2 * S
Q <- scs_cn_method(P = 50, CN = CN)

round(c(S_mm = S, Ia_mm = Ia, Q_mm = Q), digits = 3)
  S_mm  Ia_mm   Q_mm 
84.667 16.933  9.287

The retention is approximately 84.667 mm, initial abstraction is 16.933 mm, and the direct runoff depth is 9.287 mm.

6.2 Effect of the curve number

The following curves show the response to event rainfall totals from 0 to 200 mm. Every curve uses \(I_a=0.2S\). The colours and line types in the legend are the same as those used for the curves.

Code 
precipitation <- seq(0, 200, by = 1)
curve_numbers <- seq(40, 100, by = 10)

runoff_results <- sapply(curve_numbers, function(CN) {
  scs_cn_method(precipitation, CN = CN)
})

line_colors <- hcl.colors(length(curve_numbers), palette = "Dark 3")
line_types <- rep(1:3, length.out = length(curve_numbers))

plot(NULL, xlim = range(precipitation), ylim = range(runoff_results),
     xlab = "Event precipitation [mm]", ylab = "Direct runoff depth [mm]",
     main = "SCS Curve Number method")

for (i in seq_along(curve_numbers)) {
  lines(precipitation, runoff_results[, i],
        col = line_colors[i], lty = line_types[i], lwd = 1.5)
}

legend("topleft", legend = paste("CN =", curve_numbers),
       col = line_colors, lty = line_types, lwd = 1.5,
       ncol = 2, bty = "n", cex = 0.85)

6.3 A rainfall event spanning several days

The basic CN method is an event model. Initial abstraction is applied from the start of the event, and the equations do not restore retention between events or track soil drying. Applying the function separately to every day would implicitly treat each day as a new event, even when rainfall continues across midnight.

We will use the local MOPEX file introduced in the statistics chapter. Its measurement columns are precipitation, potential evaporation, runoff, maximum temperature and minimum temperature, in that order. Read the missing-value codes as NA before calculating cumulative quantities.

Code 
dat01138000 <- read.fwf("data/01138000.dly",
                        widths = c(8, rep(10, 5)),
                        header = FALSE, strip.white = TRUE,
                        na.strings = c("-99", "-99.0000"))
names(dat01138000) <- c("date", "prec", "pet", "r", "tmax", "tmin")
dat01138000$date <- as.Date(
  gsub(" ", "0", dat01138000$date), format = "%Y%m%d"
)

For this demonstration, treat the wet spell from 3 to 6 August 1953 as one rainfall event. Its total precipitation is 58.52 mm, and the immediately preceding and following days have zero precipitation. These daily observations illustrate the calculation; deciding where independent events begin and end requires attention to the data and the catchment. We use a fixed, illustrative \(\mathrm{CN}=75\) rather than a calibrated value for this catchment.

At each time step, calculate runoff from the cumulative rainfall. Then obtain the runoff excess for an individual day by taking the difference between successive cumulative runoff depths:

\[ \Delta Q_t=Q(P_{\mathrm{cum},t})-Q(P_{\mathrm{cum},t-1}), \qquad Q(P_{\mathrm{cum},0})=0. \]

Code 
event <- subset(dat01138000,
                date >= as.Date("1953-08-03") &
                date <= as.Date("1953-08-06"),
                select = c(date, prec))

# Check that the selected event is complete before accumulating rainfall.
stopifnot(nrow(event) == 4L, !anyNA(event$prec),
          all(event$prec >= 0), all(diff(event$date) == 1))

CN <- 75
event$cumulative_prec <- cumsum(event$prec)
event$cumulative_runoff <- scs_cn_method(event$cumulative_prec, CN = CN)
event$runoff <- diff(c(0, event$cumulative_runoff))

6.4 A catchment with several CN values

A catchment can contain several hydrological response units (HRUs), each with its own CN. Let \(A_i\) be the area of HRU \(i\) and \(f_i=A_i/\sum_j A_j\) its area fraction. Two approaches can be compared for uniform event rainfall:

  1. Calculate an area-weighted composite CN, then calculate runoff once:

    \[ \mathrm{CN}_{\mathrm{composite}}=\sum_i f_i\mathrm{CN}_i, \qquad Q_A=Q(P,\mathrm{CN}_{\mathrm{composite}}). \]

  2. Calculate runoff for each HRU, then average the runoff depths using area fractions:

    \[ Q_B=\sum_i f_i Q(P,\mathrm{CN}_i). \]

Both \(Q_A\) and \(Q_B\) are catchment-average runoff depths in mm. They generally differ because runoff depends nonlinearly on CN. Area weights must sum to one; percentages must be divided by 100 before using them as fractions.
